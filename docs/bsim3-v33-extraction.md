# BSIM3 v3.3 physical extraction

The native Berkeley v3.3 constitutive equations and setup stages are being moved from the qualified solver implementation at revision `439ea0903380e7f5e2a651653f595150bad61e9e` to `model-compact-intrinsic::bsim3v33`. The port uses the existing generated model parameter catalog, native typed given bits, and absolute Kelvin operating temperature. Raw native TNOM retains its Celsius input convention. The caller supplies resolved ordered model polarity and SI instance geometry. Ordered IC vectors are expanded before instance preparation.

`ModelSetup` owns the model check state and prepares immutable occurrences that share the defaulted model and temperature tables. The combined physical point evaluates DC and charge at the same normalized intrinsic bias. No numerical history, node numbering, limiting or load matrix is part of this producer module. Native capMod 3 / quasi-static / ACM 0 is the initial extraction boundary, not a substitute for other source families or versions. The existing in-tree solver remains authoritative until the new producer is independently verified and consumed; do not run both implementations in production.

The next stage must assemble the physical residual and charge through the common model-kernel ABI, including source/drain exchange and explicit series branches, then migrate native consumers and reconcile the separately qualified extrinsic junction laws. Other capMod, NQS, and revision implementations must retain independent identities.

Terminal assembly now gives physical D/G/S/B currents, stored charges and conservative analytic Jacobians, including source/drain exchange and multiplicity. A finite-difference terminal witness exposed a native CTM derivative bug: for negative `T0`, `VdseffCV = VdsatCV * T4`, and the body derivative must contain `dT0_dVb * (T4 - T5)`, not the original `dT0_dVb * (1 - T5)`. The corrected term leaves charge and DC unchanged. Native witnesses compare charge and the six unaffected intrinsic capacitance entries; the affected body/source columns are checked against the constitutive law independently. Other native derivative discrepancies near the body-bias smoothing clamp still require qualification before common ABI admission. The native oracle writes a real deck file, avoiding ngspice's stdin title consumption; verifies the applied intrinsic bias when no series nodes intervene.

The body-potential clamp now selects its exact algebraic branch instead of a cancellation-prone comparison of rounded voltages. For negative applied body bias, the smoothed potential is rationalized near the clamp; positive bias uses the applied potential and its unit derivative. The zero-bias kink takes the positive-side derivative. The reference C code retains the discarded smoothing derivative in the clamped region. Consequently native gmbs comparison is restricted to the unclamped branch, and the complete Jacobian is independently tested on both sides. The expanded terminal sweep covers 96 bias/polarity cases with asymmetric junctions and nonunit multiplicity; the native matrix covers 216 DC/charge operating points over three temperatures, three model cards, both polarities and body offsets.
